# Cabinet, window and related product inventory

Inventory date: **October 28, 2026**. Based on the current working-tree model
and room requirements, including the October 28 upstairs relocation.

This is a **design-study inventory, not an order list or construction
approval**. Dimensions below are inches unless stated otherwise. Cabinet
dimensions use **width x depth x height (W x D x H)**; window and door dimensions
use **width x height (W x H)**. Feet in model code are converted to inches.
An opening envelope, cabinet front, appliance allowance and actual product
frame are different measurements.

## What "source" means here

- **Product direction/reference:** a named manufacturer or product already
  recorded in the project; not necessarily purchased or approved.
- **Supplier TBD:** no cabinet maker, dealer, purchase SKU or technical
  submittal has been selected. Common-size boxes are not a commitment to a
  particular vendor's range.
- **Model allowance:** custom simplified geometry used to test placement.
  Fractional dimensions must not be passed off as stock cabinet sizes.
- **Visual asset:** downloaded geometry/texture or an owner inspiration image,
  not the supplier of the eventual physical product.

External links are collected from existing project records, **not newly
verified for availability or price on the inventory date**. Earlier verification
dates are identified where recorded. No geometry, product selection or saved
layout was changed to prepare this inventory.

## 6. Decisions needed before quotes or orders

1. Select the cabinet supplier/line and obtain a room-by-room shop schedule,
   retaining standard boxes with separate fillers. Resolve the sink wall,
   island, central steam tower, fractional upper/utility depths and fitted
   built-ins without silently changing owner-fixed openings or reach.
2. Obtain an Andersen dealer's exact unit/combination schedule with actual
   frame and rough-opening dimensions. Resolve front-grille documentation,
   powder privacy, safety glass, egress and mulling before an order.
3. Select actual ovens, prep dishwasher, hood insert, faucets and dispensers;
   verify cutouts, supports, ventilation, services, hot-dish landing and
   reachable controls. Reconcile laundry products with generic model shapes.
4. Select complete 96-inch door assemblies, garage rated separation and
   arched entry/lock hardware; verify openings, clear passage and operation.
5. Approve physical cabinet/metal/stone/brick/flooring samples and listed
   lighting products. Model fit, texture realism and sampled clearances do
   not establish construction, code or occupied-operation approval.

[design context](../design-context.md) and [window count](window-count.md)
when the design changes. Removed items and historical alternatives must not
be added back merely because older prose still mentions them.
